AutoModel과 AutoModelForXxx는 모델 이름으로 트랜스포머 모델 클래스를 자동 선택해 로드하는 클래스
AutoModel은 기본 모델을, AutoModelForXxx는 특정 태스크용 모델을 불러옴

#18 page
==============================================================================================================================
클래스명                              | 주요 태스크 (Task)             | 입력 -> 출력 형태               | 대표 활용 사례
==============================================================================================================================
AutoModelForSequenceClassification   | 텍스트 분류                    | 텍스트 -> 클래스별 확률/점수    | 감정 분석 (긍정/부정), 스팸 분류
AutoModelForTokenClassification      | 토큰 단위 분류                 | 텍스트 토큰들 -> 각 토큰의 태그 | 개체명 인식(NER), 품사 태깅(POS)
AutoModelForQuestionAnswering        | 독해 기반 질의응답 (Extractive)| 질문 + 본문 -> 정답 시작/끝 위치| 문서 내 정답 구절(Span) 추출
AutoModelForCausalLM                 | 인과적 언어 모델 (Decoder-only)| 프롬프트 -> 다음 토큰 생성      | ChatGPT, Llama 스타일 문장 생성/챗봇
AutoModelForSeq2SeqLM                | 시퀀스 투 시퀀스              | 입력 시퀀스 -> 출력 시퀀스      | 기계 번역(T5, BART), 문서 요약
AutoModelForMaskedLM                 | 마스크드 언어 모델             | [MASK] 포함 문장 -> 마스크 복원 | BERT 사전 학습 및 도메인 적응
AutoModelForMultipleChoice           | 다중 선택지 문제 풀이          | 질문 + N개 선택지 -> 정답 확률  | 수능/객관식 시험 문제 풀이
AutoModelForImageClassification      | 이미지 분류                    | 이미지 -> 클래스 라벨           | 동식물 분류, 제품 불량 검사 (ViT)
==============================================================================================================================
뒤에 LM 붙음 -> 글을 써주는 생성형 AI 
뒤에 Classification 붙음 -> 카테고리를 나누는 분류기
